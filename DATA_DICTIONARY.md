# Data Dictionary

## dataset/Details.csv

* `Order ID` — unique identifier for each order line item
* `Amount` — sales amount for the line item
* `Profit` — profit value for the line item
* `Quantity` — number of units sold in the line item
* `Category` — major product category
* `Sub-Category` — detailed product category
* `PaymentMode` — payment method used for the order

## dataset/Orders.csv

* `Order ID` — unique identifier for each order
* `Order Date` — date when the order was placed
* `CustomerName` — name of the customer who placed the order
* `State` — customer state or region
* `City` — customer city
